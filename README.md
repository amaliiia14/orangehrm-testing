# OrangeHRM Testing dengan Cypress

## Deskripsi

Project ini merupakan **automation testing** pada fitur Login website OrangeHRM menggunakan Cypress.

## Tools

* Cypress 14.0.2
* JavaScript
* Node.js

## Pengujian

Pengujian mencakup:

* Login dengan data valid
* Login dengan data tidak valid
* Username atau password kosong
* Input berupa spasi
* Pengujian huruf besar dan kecil
* Username dan password dengan spasi di awal/akhir

## Cara Menjalankan

Install dependencies:

```bash
npm install
```

Jalankan Cypress:

```bash
npx cypress open
```
